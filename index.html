What's in the box

A real app, not a tech demo

Two ways to play, one ruleset, zero paid infrastructure.

Three AI difficulties

Minimax with alpha-beta pruning and move ordering. Hard runs iterative deepening on a 900 ms budget inside a background isolate, so the board never freezes.

Online, room-code PvP

Four-letter codes (no 0/O/1/I), Realtime-Database-backed, with onDisconnect presence and network pass support.

Fairness without a server

No Cloud Functions on the free tier — so every client re-derives each move and rejects the room on mismatch. More below.

Entirely free-tier

Architecture note

Dual-compute instead of a server

Cloud Functions need a billing account; this project doesn't use one. So there's no referee process adjudicating moves — instead, every client holds the same pure-Dart engine and independently replays each move against its own copy of the position.

The Realtime Database transaction still enforces turn order and basic shape, but the actual rules check happens twice, on two machines that don't trust each other. A mismatch rejects the move and the room is left — the exact pattern exercised in test/features/multiplayer/room_flow_test.dart.

Interface

Wood, honey, clay — not a spreadsheet

The theme (lib/core/theme/colors.dart) is tuned for outdoor Addis sunlight and a board that should feel carved, not flat: warm cream surfaces, a wood gradient board, honey-gold seed dots, gold glow on legal moves. These are CSS recreations of the real widget tree — PitCircle, GebetaBoard, HomeScreen — side by side with the live app so you can compare the two directly.
